# Domain Docs

This repository uses a single-context domain layout.

## Before exploring

Read these files when they exist:

- `CONTEXT.md` at the repository root
- Relevant architectural decisions under `docs/adr/`

If they do not exist, proceed without requiring them. Domain-modeling workflows create them when terminology or decisions are established.

## Vocabulary

Use the terminology defined in `CONTEXT.md` in issue titles, proposals, hypotheses, and test names. Avoid synonyms that the glossary explicitly rejects.

## Architectural decisions

Surface any conflict with an existing ADR explicitly rather than silently overriding it.
