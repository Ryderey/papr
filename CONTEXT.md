# Papr

Papr is a reading workspace for organizing subscription articles and reading them with optional AI assistance.

## Language

**Article List**:
A browsable set of articles belonging to the currently selected source or filter.
_Avoid_: Middle pane, feed list

**Reader**:
The primary surface for reading the currently selected article.
_Avoid_: Article pane, content pane

**AI Summary Drawer**:
A companion reading surface containing an AI-generated summary and follow-up questions for the current article.
_Avoid_: AI panel, summary region
