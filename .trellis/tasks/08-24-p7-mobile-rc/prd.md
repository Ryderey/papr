# P7 移动范围验收与可发布 RC

## Goal

按精简后的移动端范围完成集成、兼容、无障碍、安全、升级和发布验证，交付可进入 Google Play 内测的 Release Candidate。

## Requirements

1. 建立“已实现 / Android 替代 / 明确排除”范围矩阵，禁止用桌面功能数量作为完成度。
2. 校对中/英/日文案，覆盖动态字体、窄屏/平板、TalkBack、触控目标、颜色对比、减少动画与深色模式。
3. 验证 Android 10、一个中间版本、当前稳定版本和至少一种平板尺寸。
4. 覆盖冷启动、大数据库、长文章、长音频、后台刷新、同步重放和进程恢复。
5. 从正式 Alpha schema 连续升级到 RC，不清库；验证安装、升级、卸载/清除数据语义。
6. 构建签名 Release APK/AAB，签名材料只存在本地安全环境或 CI Secret。
7. 提供隐私说明，覆盖本地数据、Feed/AI/翻译/同步请求、凭据和删除方式。

## Acceptance Criteria

- [ ] P0–P6 全部精简范围任务已归档，未完成项均有明确排除依据。
- [ ] Rust、FRB、Flutter、桌面回归和 Release 构建全部通过。
- [ ] 无阻塞级崩溃、数据丢失、密钥泄漏或迁移问题。
- [ ] 真实设备完成订阅→刷新→阅读→整理→摘要/翻译→播放→同步主链路。
- [ ] Release AAB 可安装、从 Alpha 升级、启动并满足 Google Play 内测技术准备。

## Dependencies / Out of Scope

依赖 P3–P6 归档。商店截图、营销文案、运营投放不属于本任务；签名密钥不提交仓库。
