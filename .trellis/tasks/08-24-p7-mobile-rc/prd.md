# P7 移动范围验收与内部 RC

## Goal

按精简后的移动端范围完成集成、兼容、无障碍、安全和自动化迁移验证，交付供个人使用的内部 Release Candidate。

## Requirements

1. 建立“已实现 / Android 替代 / 明确排除”范围矩阵，禁止用桌面功能数量作为完成度。
2. 校对中/英/日文案，覆盖动态字体、窄屏/平板、TalkBack、触控目标、颜色对比、减少动画与深色模式。
3. 验证 Android 10、一个中间版本、当前稳定版本和至少一种平板尺寸；可使用模拟器及 Widget 测试。
4. 覆盖冷启动、大数据库、长文章、长音频、后台刷新、同步重放和进程恢复。
5. 以自动化测试验证正式 Alpha schema 连续迁移不清库；验证内部测试包安装/升级及清除数据语义。
6. 构建内部测试 APK，记录版本、校验值和签名证书指纹；内部构建可使用 Android Debug 签名。
7. 提供隐私说明，覆盖本地数据、Feed/AI/翻译/同步请求、凭据和删除方式。

## Acceptance Criteria

- [ ] P0–P6 全部精简范围任务已归档，未完成项均有明确排除依据。
- [ ] Rust、FRB、Flutter、桌面回归和 Release 构建全部通过。
- [ ] 无阻塞级崩溃、数据丢失、密钥泄漏或迁移问题。
- [ ] 在模拟器和自动化测试中覆盖订阅→刷新→阅读→整理→摘要/翻译→播放→同步主链路。
- [ ] 内部测试 APK 可安装、从同证书测试包升级并启动；Core 的 Alpha schema 迁移测试通过。

## Dependencies / Out of Scope

依赖 P3–P6 归档。实体机验收和正式 Alpha APK 原位升级按 2026-09-28 的自用范围决定跳过；正式签名、AAB、Google Play 上架和商店运营材料也不属于本任务，未来有分发需求时另行规划。内部签名材料不提交仓库。
