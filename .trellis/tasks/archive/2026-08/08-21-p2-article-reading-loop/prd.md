# P2 文章列表、智能视图与完整阅读闭环

## Goal

在 Android Flutter 客户端完成从“找到文章”到“阅读、整理、分享”的完整闭环，并保持 SQLite、搜索、全文提取和文章状态规则只在 `papr-core` 实现。

## Background

- P1 已通过自动化与实体机验收，移动端已有自适应顶层导航、Feed/文件夹管理、文章基础列表和安全 HTML 阅读器。
- `papr-core` 已有 `ArticleFilterKind`、基础分页字段、文章详情 DTO、FTS5、标签表、正文/提取正文及三种文章状态字段，但标签筛选、搜索、排序、计数、状态写入和全文提取服务尚未完成。
- 桌面端已有成熟的文章查询、FTS 查询构造、状态写入、批量已读、智能计数和 Readability 全文提取逻辑，可机械下沉。
- Android 平台通道已用于 OPML 与深链，可继续承载系统浏览器和分享，不新增插件依赖。

## Requirements

1. 提供全部、未读、收藏、稍后读、Feed、文件夹和标签文章视图，并显示实时计数。
2. 列表查询支持安全的 `limit + offset` 分页、FTS5 全文搜索、正序/倒序、隐藏已读；默认页大小 50，禁止一次加载全部数据。
3. 列表显示来源、标题、摘要、有效发布时间、缩略图和未读状态；空值与图片加载失败有稳定占位。
4. 支持打开即标记已读、手动切换已读、收藏、稍后读和按当前筛选批量标记已读。单篇状态在 UI 乐观更新，失败恢复旧值并提示。
5. 阅读器优先显示 `extracted_html`，回退 `content_html`；正文继续由 Rust 清洗，相对链接基于文章 URL 解析，正文链接交给外部浏览器。
6. 支持手动全文提取、重新提取和自动全文设置；提取写入需更新 FTS/缩略图并清除旧翻译缓存，失败不覆盖现有正文。
7. 阅读设置包含字体（system/serif/sans）、字号、行距、最大阅读宽度、显示阅读时长和自动全文，并持久化到 Core settings。
8. 有原文 URL 时支持系统浏览器和 Android 分享面板（标题 + URL）；无 URL 时相关操作禁用。
9. 复用 P0 变更日志事务合同：文章状态与对应 `change_log` 同事务提交；本地操作离线可用。

## Acceptance Criteria

- [ ] 智能视图及 Feed/文件夹/标签筛选返回正确结果与计数，搜索词经过安全 FTS 转换。
- [ ] 10,000 篇文章场景使用 50 条分页，不执行无界列表查询；加载更多、筛选、搜索和排序不会丢项或重复。
- [ ] 打开文章、已读、收藏和稍后读更新列表归属、计数与详情；模拟写入失败时 UI 回滚且数据库/change_log 无半写入。
- [ ] 批量已读只影响当前筛选范围，重复执行幂等。
- [ ] 全文提取优先展示，重新提取覆盖旧提取正文，写入时刷新 FTS/封面并清空翻译缓存；提取失败保留旧缓存。
- [ ] 恶意脚本、事件属性、危险 URL 在 Rust 清洗层被移除，离线仍能阅读缓存正文并修改本地状态。
- [ ] 阅读设置重启后保持；正文宽度、字号和行距即时生效，阅读时长可关闭。
- [ ] 无 URL 时浏览器/分享禁用；有 URL 时 Android 系统浏览器和分享面板可用。
- [ ] 手机/平板、返回导航、旋转和进程恢复通过测试或实体机验收。
- [ ] FRB 绑定生成幂等；`cargo test -p papr-core`、`cargo test -p papr-flutter-bridge`、`cargo test -p papr`、`flutter analyze`、`flutter test`、Debug APK 构建全绿。

## Out of Scope

- 标签 CRUD、规则和高亮（P3）；P2 仅只读现有标签并用于筛选。
- AI 摘要、翻译生成和问答（P4）；P2 只负责全文提取后清除过期翻译缓存。
- Podcast 播放、Newsletter、高级来源（P5）。
- 后台刷新、通知和外部同步协议（P6）。
