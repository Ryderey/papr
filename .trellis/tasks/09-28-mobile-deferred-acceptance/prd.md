# Android 按需扩展验收

## Goal

保留 P7 自用内部 RC 未完成的验收项目；当扩大自用场景、依赖重要数据或向他人分发时，再规划执行。此任务处于 planning，不阻断当前自用 RC。

## Requirements

1. 校对中、英、日文案，并覆盖动态字体、窄屏与平板、TalkBack、触控目标、颜色对比、减少动画及深色模式。
2. 在 Android 10、一个中间 API 版本、当前稳定版本和至少一种平板尺寸上完成兼容矩阵；P7 已有 API 37 手机烟测和 Widget 窄屏/平板布局测试，可复用其证据。
3. 覆盖大数据库、长文章、长音频、后台刷新与进程恢复、同步重放等压力和故障场景。
4. 在模拟器或自动化环境中验证订阅→刷新→阅读→整理→摘要/翻译→播放→同步主链路，并记录需要外部服务的配置和替代方案。
5. 直接核查清除数据后的数据库文件、Keystore 别名、同步凭据删除、Android 备份恢复和通知权限行为。不得在包含用户真实数据的设备上执行破坏性验证。

## Acceptance Criteria

- [ ] 上述矩阵逐项记录设备/自动化证据及明确的未验证项；发现问题时建立修复任务并复测。
- [ ] 完整业务链路和数据安全检查有可重复的结果，且没有阻断级数据丢失或凭据残留问题。
- [ ] 扩大使用或分发前重新运行适用的 Rust、Bridge、Flutter、桌面回归和 APK 构建门禁。

## Dependencies / Out of Scope

来源：P7 自用 RC 的延期项目，见 `docs/mobile-rc-scope-matrix.md` 和 `docs/mobile-privacy.md`。实体机、正式 Alpha APK 原位升级、正式签名、AAB 和应用商店仅在未来确有分发需求时另行决定，不作为本任务自动要求。
